1. Layer-wise Error (The "Sensitivity" Map)Plot: Line chart.Axes: X: Layer Index (0–31) | Y: Relative Error ($e_k$ or $e_v$).Goal: See which versions "spike" in the middle layers. This identifies where $K$ bits are most critical.2. Attention KL-Divergence (The "Logic" Check)Plot: Grouped Bar or Violin plot.Axes: X: Quantized Version | Y: KL-Divergence from BF16 Attention.Goal: Measure how much the "focus" of the model shifted. A high shift here usually predicts a fail on GSM8K.3. Bit-Rate vs. Accuracy (The "Efficiency" Pareto)Plot: Scatter plot.Axes: X: Average Bits per KV pair | Y: GSM8K Accuracy (or Mean Output Error $e_o$).Goal: The "Money Shot." It proves which version (e.g., K4V2 vs. K2V4) gives the best performance for the smallest memory footprint.
